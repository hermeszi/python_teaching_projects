STAR Framework

Project Overview

Best for: behavioral & design questions
S Situation
When I reached Level 4 at Code Ninja, I moved from drag-and-drop blocks to writing real Python code. I wanted to build a game completely on my own — something bigger than anything I'd made before.
T Task
My task was to build a full Snake game from scratch in Python, using a library called Tkinter to create the game window. I had to make the snake move, keep it inside the grid, and detect crashes — all without copying a template.
A Action
I kept track of the snake's body as a list of (x, y) positions. To stop it from doubling back on itself, I wrote if-statements that blocked it from reversing direction. When I rushed and my code broke in a few places at once, I slowed down and used print statements to check my values at each step until I found the bug.
R Result
I ended up with a working game that keeps score, restarts after you lose, and shows a proper game-over screen. It proved to me that I could manage all the moving parts of a program without everything falling apart.
OSCAR Framework

Problem Solving Process

Best for: analytical & technical depth
O Outcome
My goal was to build a clean, working game that shows I understand how to track positions and coordinates in code — a core skill in programming.
S Situation
I set up the project on my own laptop using VS Code, and tested it by running the game and checking that key presses and window updates worked properly.
C Challenge
The hardest part was updating the snake's tail as it grew. Every time it ate food, I had to add a new position to the list smoothly, without the snake jumping or glitching on the grid.
A Action
I added a check inside my game loop that only added a new body block after confirming the snake's new position. This kept my code organized into clear, separate steps instead of one messy block.
R Result
The snake now grows correctly every time, with no glitches. My code is also easy to read, which made it simple to upload and share on GitHub.
STAR Framework

Project Overview

Best for: analytics & structured logic
S Situation
I wanted to try using my coding skills on something closer to real-world business problems, so I moved from building games to working with data.
T Task
My task was to look through the Titanic passenger dataset, fix the missing or messy entries, create some new useful columns, and build a model that could predict who survived.
A Action
I loaded the data using a tool called Pandas. Instead of just deleting rows with missing ages, I filled them in using the median age for each passenger class — a more accurate way to estimate. I also created new columns like FamilySize, IsChild, and IsAlone, then used them to train a Decision Tree model with Scikit-learn.
R Result
I ended up with a working prediction model in a clean Google Colab notebook. It proved to me that I can take messy real-world data and turn it into something useful.
OSCAR Framework

Problem Solving Process

Best for: AI understanding & analytics depth
O Outcome
My goal was to improve the model's accuracy, clean up the missing information, and be able to clearly explain how the model makes its decisions.
S Situation
I worked inside Google Colab, which let me write and run my Python code in the cloud without installing anything extra.
C Challenge
The biggest challenge was filling in missing information without messing up the patterns in the data, and then being able to explain, step by step, how the Decision Tree actually reaches a decision.
A Action
I filled in missing ages by grouping passengers by class and taking the median age for each group. Then I practiced explaining, out loud, how the Decision Tree checks one condition at a time to reach its final answer.
R Result
I built the model and explained it clearly in a full mock presentation. That gave me real confidence that I understand both the coding and the reasoning behind it — not just the code.
